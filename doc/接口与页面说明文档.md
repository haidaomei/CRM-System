## 第一章 项目概述

### 1.1 路由规范

所有业务 Servlet 使用 `@WebServlet("/xxx/*")` 通配符 + `getPathInfo()` 子路由模式：

| 规则 | 说明 |
|------|------|
| URL 映射 | `@WebServlet` 用通配符 `"/xxx/*"` |
| 子路由分发 | `pathInfo` 取值后用 `if-else` 匹配 |
| NPE 防护 | `"/list".equals(pathInfo)` 防 null |
| doGet | 只处理展示类路由（list/add/edit/detail） |
| doPost | 只处理写操作（save/delete） |
| 显示响应 | `setAttribute` + `forward` → JSP |
| 写操作响应 | 取参 → new 实体 → Service → `redirect` |
| 重定向 | `request.getContextPath() + "/路由"` |
| PRG 模式 | POST 成功 → redirect → Flash 消息通过 Session 传递 |

### 1.2 BaseServlet 公共方法

`servlet/BaseServlet.java` 是所有业务 Servlet（除 CheckCodeServlet、LogoutServlet）的抽象父类，提供以下公共能力：

| 方法 | 说明 |
|------|------|
| `utf8(req, resp)` | 设置请求/响应 UTF-8 编码，Content-Type `text/html;charset=UTF-8` |
| `intVal(value, fallback)` | 安全字符串转 int，失败返回 fallback |
| `integer(value)` | 安全字符串转 Integer，失败返回 null |
| `decimal(value)` | 安全字符串转 BigDecimal，失败返回 `BigDecimal.ZERO` |
| `keyword(req)` | 读取 `keyword` 参数，trim 后返回，null 返回 `""` |
| `user(req)` | 从 Session 中取 `"user"` 属性（当前登录用户） |
| `flash(req, ok, success)` | 向 Session 写入 flash 消息（`flashType`、`flashMsg`） |
| `forward(req, resp, jsp)` | 服务端转发（`RequestDispatcher`） |
| `redirect(req, resp, path)` | 客户端重定向（带 `contextPath` 前缀） |

## 第二章 Servlet 接口映射清单

### 2.1 认证模块

#### 2.1.1 模块总览

| Servlet | URL | 方法 | 功能 |
|---------|-----|------|------|
| LoginServlet | /login | GET, POST | 登录（显示表单 / 验证登录） |
| RegisterServlet | /register | GET, POST | 注册（显示表单 / 创建用户） |
| LogoutServlet | /logout | GET | 退出登录 |
| CheckCodeServlet | /checkCodeServlet | GET | 生成验证码图片 |

#### 2.1.2 /login — 登录

**【GET】显示登录页**

| 项目 | 说明 |
|------|------|
| URL | /login |
| 方法 | GET |
| 参数 | 无 |
| 处理 | 读取 Cookie `username`、`password`，设置 request 属性 `rememberedUsername`、`rememberedPassword`、`remembered` |
| 响应 | forward → `/login.jsp` |

**【POST】验证登录**

| 项目 | 说明 |
|------|------|
| URL | /login |
| 方法 | POST |
| Content-Type | application/x-www-form-urlencoded |

请求参数：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| username | String | 是 | 用户名 |
| password | String | 是 | 密码 |
| code | String | 是 | 验证码（4位） |
| remember | String | 否 | "1" 表示勾选"记住我" |

处理流程：
1. 校验验证码 → 从 Session 取 `checkCode`，忽略大小写比较
2. 调用 `LoginService.login(username, password)` 查询用户
3. 成功：Session 存入 `user`，根据 `remember` 参数写入/清除 Cookie（7天），redirect → `/dashboard`
4. 失败：设置 `error` 属性，forward → `/login.jsp`（回显用户名密码）

#### 2.1.3 /register — 注册

**【GET】显示注册页**

| 项目 | 说明 |
|------|------|
| URL | /register |
| 方法 | GET |
| 参数 | 无 |
| 响应 | forward → `/register.jsp` |

**【POST】提交注册**

| 项目 | 说明 |
|------|------|
| URL | /register |
| 方法 | POST |

请求参数：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| username | String | 是 | 用户名 |
| password | String | 是 | 密码（最少6位） |
| confirmPassword | String | 是 | 确认密码（须与 password 一致） |
| code | String | 是 | 验证码（4位） |
| realName | String | 是 | 真实姓名 |
| phone | String | 否 | 电话 |
| email | String | 否 | 邮箱 |

处理流程：
1. 校验验证码
2. 校验 `password` 与 `confirmPassword` 一致
3. 校验密码长度 ≥ 6
4. 校验用户名唯一性
5. 封装 User 对象（role 固定为 "sales"）
6. 调用 `LoginService.register(user)`
7. 成功：redirect → `/login`
8. 失败：forward → `/register.jsp`（带 `error` 属性）

#### 2.1.4 /logout — 退出登录

| 项目 | 说明 |
|------|------|
| URL | /logout |
| 方法 | GET |
| 处理 | `session.invalidate()` 销毁 Session |
| 响应 | redirect → `/login` |
| 备注 | Cookie 不清除（保留"记住我"功能） |

#### 2.1.5 /checkCodeServlet — 验证码图片

| 项目 | 说明 |
|------|------|
| URL | /checkCodeServlet |
| 方法 | GET |
| 参数 | 无（`?t=` 时间戳用于防缓存） |
| Content-Type | image/jpeg |
| Cache-Control | no-store, no-cache, must-revalidate |
| 处理 | 生成 112×38 像素 4 位字符 JPEG 图片，正确答案存入 Session `"checkCode"` |
| 字符规则 | 至少包含数字、小写字母、大写字母各一个，含旋转（±38°）、剪切、噪点、贝塞尔曲线干扰 |

- `createUserId` 强制取 Session 当前用户
- 新增时自动生成合同编号（HT+yyyyMMdd+4位流水号）
- Service 校验：至少一条明细、日期合法性、同商机不可重复生成合同
- 合同金额由明细自动汇总

#### 2.8.7 POST /contract/delete — 删除合同

请求参数：`id` (int)

业务逻辑：逻辑删除（status=0）

### 4.3 核心业务流程跳转

**登录注册流程**：
```
index.jsp → /login (LoginServlet GET) → login.jsp
    ↓ POST
LoginServlet POST → 成功: /dashboard (DashboardServlet) → dashboard.jsp
                  → 失败: login.jsp
login.jsp → "注册账号" → /register (RegisterServlet GET) → register.jsp
    ↓ POST
RegisterServlet POST → 成功: /login
                     → 失败: register.jsp
```

**客户 CRUD 流程**：
```
/customer/list (GET) → customer_list.jsp
    ├── "新增" → /customer/add (GET) → customer_form.jsp → POST /customer/save → redirect /customer/list
    ├── "详情" → /customer/detail (GET) → customer_detail.jsp
    ├── "编辑" → /customer/edit (GET) → customer_form.jsp → POST /customer/save → redirect /customer/list
    └── "删除" → POST /customer/delete → redirect /customer/list

customer_detail.jsp
    ├── "转移" → POST /customer/transfer → redirect /customer/list
    ├── "立即跟进" → /follow/add?customerId=X → follow_form.jsp
    ├── "新增联系人" → /contact/add?customerId=X → contact_form.jsp
    └── "新增商机" → /opportunity/add?customerId=X → opportunity_form.jsp
```

**商机到合同流程**：
```
opportunity_detail.jsp (businessStatus="已成交")
    └── "生成合同" → /contract/add?opportunityId=X (GET) → contract_form.jsp (自动预填)
        └── POST /contract/save → redirect /contract/list
```

**跟进记录流程**：
```
dashboard.jsp / customer_detail.jsp / warning_customer.jsp
    └── "跟进" → /follow/add?customerId=X (GET) → follow_form.jsp
        └── POST /follow/save → redirect /follow/list
```

|------|--------|-----------|------|----------|
| 1 | LoginFilter | /* | 登录状态检查，白名单放行 | redirect /login |
| 2 | AuthorizationFilter | /product/*, /customer/transfer | 销售角色禁止访问产品管理和客户转移 | 403 + /error.jsp |
| 3 | OwnershipFilter | /customer/*, /contact/*, /opportunity/*, /follow/*, /contract/* | 销售员数据归属检查（仅 POST） | 403 + /error.jsp |
| 4 | NavigationDataFilter | /* | 全局加载预警数量到 request | 异常静默忽略 |

### 5.2 LoginFilter

- **URL 模式**：`/*`（全局）
- **白名单路径**（startsWith 匹配）：
  - `/login`
  - `/register.jsp`、`/register`
  - `/checkCodeServlet`
  - `/static/`
  - `/error.jsp`
- **特殊处理**：直接访问 `/login.jsp` → redirect `/login`（确保 LoginServlet 读取 Cookie）
- **未登录处理**：redirect `/login`
- **已登录处理**：`chain.doFilter()` 放行
- **全局编码**：`req.setCharacterEncoding("UTF-8")` + `resp.setCharacterEncoding("UTF-8")`

### 5.3 AuthorizationFilter

- **URL 模式**：`/product/*`、`/customer/transfer`
- **触发条件**：`user.isSales()` 返回 true（当前用户为销售员角色）
- **失败响应**：HTTP 403，设置 `errorMessage="您没有权限访问此功能"`，forward → `/error.jsp`
- **防御性编程**：user 为 null 时 redirect `/login.jsp`

### 5.4 OwnershipFilter

- **URL 模式**：`/customer/*`、`/contact/*`、`/opportunity/*`、`/follow/*`、`/contract/*`
- **触发条件**：已登录 + 销售员角色 + POST 方法
- **归属校验方式**：

| 路径前缀 | 校验方式 |
|----------|----------|
| /customer/*（id>0） | `CustomerService.get(id, user) != null` |
| /contact/*（id>0） | `ContactService.get(id, user) != null` |
| /opportunity/*（id>0） | `OpportunityService.get(id, user) != null` |
| /follow/delete（id>0） | `FollowUpService.accessible(id, user)` |
| /contract/*（id>0） | `ContractService.get(id, user) != null` |
| 以上路径无 id 但有 customerId | 检查 customerId 是否属于该销售员的客户列表 |

- **失败响应**：HTTP 403，`errorMessage="不能修改不属于您的客户数据"`，forward → `/error.jsp`

### 5.5 NavigationDataFilter

- **URL 模式**：`/*`（全局）
- **触发条件**：已登录用户
- **功能**：调用 `DashboardService.stats(user).getWarningCount()`，将预警数写入 request 属性 `"warningCount"`
- **异常处理**：try-catch 包裹，查询失败不影响主页面打开
- **用途**：navbar.jsp 和 sidebar.jsp 显示预警角标

### 附录 G：编码约定

| 约定 | 说明 |
|------|------|
| 编码 | 全链路 UTF-8（Filter → Servlet → JSP → MySQL） |
| 分页 | 统一 PageBean\<T\> 结构，每页 10 条 |
| 删除 | 全系统逻辑删除（UPDATE SET status=0），不使用物理 DELETE |
| 事务 | Service 层手动事务（getConnection → setAutoCommit(false) → dao → commit/rollback → close） |
| 写操作 | 统一 PRG 模式（Post/Redirect/Get），Flash 消息存 Session |
| SQL | 全部参数化（? 占位符 + PreparedStatement），禁止字符串拼接 |
| JSP | 仅使用 EL 表达式和 JSTL 标签，禁止 `<% %>` 脚本 |
| 日期 | 实体用 String 存储，SQL 用 DATE_FORMAT 格式化 |
| 金额 | BigDecimal，服务端计算小计（不信任前端传值） |
