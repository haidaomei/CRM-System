## 1 项目概述

### 1.1 路由规范

| 规则 | 说明 |
|------|------|
| URL 映射 | `@WebServlet("/xxx/*")` + `getPathInfo()` 子路由 |
| doGet | 展示类：list / add / edit / detail |
| doPost | 写操作：save / delete |
| 响应 | doGet → `setAttribute` + `forward` → JSP；doPost → `redirect`（PRG） |
| Flash | Session 传递，`flashType`(success/error) + `flashMsg`(正文) |

### 1.2 公共方法

| 方法 | 返回 | 作用 |
|------|------|------|
| `user(req)` | User | 取 Session 当前用户 |
| `intVal(v, d)` | int | String→int，失败返 d |
| `integer(v)` | Integer | String→Integer，失败返 null |
| `decimal(v)` | BigDecimal | String→BigDecimal，失败返 0 |
| `flash(req, ok, s)` | void | 设 flashType + flashMsg |
| `forward(req, r, jsp)` | void | 转发到 JSP |
| `redirect(req, r, p)` | void | 重定向（拼 contextPath） |

### 1.3 会话属性

| Key | 类型 | 设置者 |
|-----|------|--------|
| user | User | LoginServlet |
| checkCode | String | CheckCodeServlet |
| flashType | String | 各 Servlet |
| flashMsg | String | 各 Servlet |

### 1.4 公共约定

**`activeMenu`**：所有业务 JSP 从 request 读取 `activeMenu`(String)，用于侧边栏高亮当前菜单项，值固定为模块英文名（`customer` / `contact` / `product` / `opportunity` / `follow` / `contract` / `dashboard` / `warning` / `funnel`）。

## 附录

### A：参数约定

| 约定 | 说明 |
|------|------|
| 分页 | `currentPage`(int,默认1), 服务端固定 10 条/页 |
| 搜索 | `keyword`(String)，参数化 LIKE |
| 同位数组 | `items[][xxx]` 三参数同一下标为一组 |
| 复选框 | 勾选传 `"1"` |
| datetime-local | `yyyy-MM-ddTHH:mm` → 服务端转 `yyyy-MM-dd HH:mm:ss` |

### B：响应约定

| 类型 | Content-Type |
|------|-------------|
| 页面 | text/html;charset=UTF-8 |
| JSON | application/json;charset=UTF-8 |
| 图片 | image/jpeg |
| 重定向 | HTTP 302 |

### C：业务编号

| 实体 | 前缀 | 格式 |
