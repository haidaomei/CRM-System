## 第一章 项目概述

### 1.1 路由规范

所有业务 Servlet 使用 `@WebServlet("/xxx/*")` + `getPathInfo()` 子路由模式：

| 规则 | 说明 |
|------|------|
| URL 映射 | `@WebServlet` 通配符 `"/xxx/*"` |
| 子路由分发 | `pathInfo` 取值后用 `if-else` 匹配 |
| doGet | 展示类路由（list/add/edit/detail） |
| doPost | 写操作（save/delete） |
| 响应方式 | doGet → `setAttribute` + `forward` → JSP |
| 写操作响应 | doPost → `redirect`（PRG 模式） |
| Flash 消息 | 通过 Session 传递，JSP 消费后清除 |

### 1.2 公共方法(BaseServlet)

| 方法 | 返回值 | 说明 |
|------|--------|------|
| `utf8(req, resp)` | void | 设置请求/响应 UTF-8 编码 |
| `intVal(value, fallback)` | int | String → int，失败返回 fallback |
| `integer(value)` | Integer | String → Integer，失败返回 null |
| `decimal(value)` | BigDecimal | String → BigDecimal，失败返回 0 |
| `user(req)` | User | 从 Session 取当前登录用户 |
| `flash(req, ok, success)` | void | 向 Session 写入 flashType + flashMsg |
| `forward(req, resp, jsp)` | void | 转发到 JSP |
| `redirect(req, resp, path)` | void | 重定向（自动拼接 contextPath） |

### 1.4 数据库配置

| 配置项 | 值 |
|--------|-----|
| JDBC 驱动 | com.mysql.cj.jdbc.Driver |
| 连接 URL | `jdbc:mysql:///crm_db?...` |

### 1.5 Session 属性

| Key | 类型 | 说明 | 设置者 |
|-----|------|------|--------|

| flashType | String | "success" / "error" | 各 Servlet |
| flashMsg | String | 提示消息正文 | 各 Servlet |

## 第二章 接口清单

### 2.1 认证模块

#### 2.1.1 接口总览

| URL | 方法 | 功能 | 响应类型 |
|-----|------|------|---------|
| /login | GET | 显示登录页 | forward → login.jsp |
| /login | POST | 登录验证 | redirect → /dashboard 或 forward → login.jsp |
| /register | GET | 显示注册页 | forward → register.jsp |
| /register | POST | 注册新用户 | redirect → /login 或 forward → register.jsp |
| /logout | GET | 退出登录 | redirect → /login |
| /checkCodeServlet | GET | 生成验证码图片 | image/jpeg |

#### 2.1.2 POST /login

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| username | String | 是 | 登录用户名 |
| password | String | 是 | 密码 |
| code | String | 是 | 验证码（4位） |
| remember | String | 否 | "1"表示记住我 |

成功时 Session 写入 `user`，设置 Cookie（`remember=1` 时 7 天）。

#### 2.1.3 POST /register

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| username | String | 是 | 用户名 |
| password | String | 是 | 密码，≥6 位 |
| confirmPassword | String | 是 | 确认密码 |
| code | String | 是 | 验证码 |
| realName | String | 是 | 真实姓名 |
| phone | String | 否 | 电话 |
| email | String | 否 | 邮箱 |

注册角色固定为 sales。失败时 JSP 从 `requestScope.error` 读取错误信息。

### E：编码约定

| 约定 | 说明 |
|------|------|
| 编码 | 全链路 UTF-8 |
| 分页 | PageBean\<T\>，每页 10 条 |

| 事务 | Service 手动事务（getConnection → commit/rollback → close） |
| 写操作 | PRG 模式，Flash 消息存 Session |
| SQL | 参数化查询（? 占位符） |
| JSP | 仅 EL + JSTL，禁止 `<% %>` |
| 日期 | 实体用 String，SQL 用 DATE_FORMAT |
| 金额 | BigDecimal，服务端计算 |
